## Como valido uma entrega

- **Regra de negócio** — Confirmo o significado dos indicadores e o comportamento esperado dos filtros com a área responsável.
- **Consistência dos dados** — Comparo os valores da origem, da API e do painel em recortes relevantes para a análise.
- **Performance** — Investigo gargalos em consultas, medidas, modelos e interfaces.
- **Manutenção** — Trabalho com versionamento, documentação e testes para facilitar a revisão e a continuidade das soluções.
